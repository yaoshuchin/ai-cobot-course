## 🚀 本地啟動與瀏覽

免密碼限制，直接啟動即可觀看：

### 方式一：一鍵啟動（推薦）
直接雙擊專案目錄下的 **start_local.bat**，會自動啟動本地伺服器並用預設瀏覽器開啟首頁。

### 方式二：使用 Python 或 Node.js
在終端機進入專案目錄，執行：
`ash
python -m http.server 8080
`
或
`ash
npx serve -l 8080
`
接著在瀏覽器打開：
- 課程首頁：[http://localhost:8080/](http://localhost:8080/)（免密碼直接瀏覽）
