# U02 機器人找路實驗室技能包

## 你要做的事
使用者是中學老師，不會寫程式。你負責：寫好 Godot 專案 → 自己驗證 → 匯出網頁版 → 用白話回報。做不到的事直接說原因。

## 一定要遵守的規範
1. **Godot 4.7、只用 GDScript**，不用 C#、不裝外掛、不下載素材。全部用 2D 繪圖（`_draw()`、ColorRect、Label）完成，不需要任何圖片。
2. 場景用程式建立：`main.tscn` 只放根節點掛 `main.gd`。程式可分 `main.gd`（畫面與操作）、`grid.gd`（地圖資料）、`planner.gd`（演算法）、`hud.gd`（右側面板），每個檔都要有中文註解。
3. **演算法要自己寫，並且「一步一步」可視化**（教學重點）：
   - `planner.gd` 提供 `bfs(start, goal)` 與 `astar(start, goal)`，回傳：路線、探索順序（每一格被「看過」的先後）、找過的格數、路線步數、路線總花費。
   - BFS 不管地形成本（每格都算 1 步）；A* 要把泥巴成本算進去（啟發函數用曼哈頓距離），所以 A* 會繞過泥巴、BFS 會直接穿過去。
   - 不可以用 Godot 內建的 AStarGrid2D（學生要看得到演算法本身）。
4. **畫面（亮點）**：
   - 左右並排兩張一樣的地圖：左邊「A* 小藍」、右邊「BFS 小橘」（名字顏色從 robot.json 讀）。
   - 按「開始比賽」：先播放「找路動畫」——依探索順序把格子一格一格塗上淡色（越早越亮，像水波擴散），速度可調；再讓兩台機器人沿路線同時走，走過的地方留下軌跡。
   - 誰先到終點，頭上冒出「🏁 抵達」與名次；右側面板即時顯示兩邊的：找過幾格、路線幾步、總花費、用時。
   - 地圖格子要有清楚的顏色：牆深灰、地板淺色、泥巴咖啡色並標「×3」、起點綠色 S、終點紅旗 G。
5. **編輯地圖**（滑鼠與觸控都要能用）：上方工具列按鈕「牆」「泥巴」「橡皮擦」「起點」「終點」，選好後在任一張地圖上點或拖曳就能畫，兩張地圖同步。另有「隨機迷宮」「清空」「重新比賽」。
6. **能讓使用者改的東西全放設定檔**（欄位見 `references/設定檔說明.md`）：`map.txt`（地圖）、`robot.json`（兩台機器人名字、顏色、移動速度、軌跡）、`lab.json`（動畫速度、泥巴成本、是否允許斜走、標題）。讀不到或欄位缺少時用預設值，畫面左下角用中文提示，不可當掉。
7. 中文字型：把 `assets/fonts/NotoSansTC-Common.ttf` 複製到專案 `fonts/`，建 Theme 設成預設字型（網頁版沒有系統字型）。畫面文字避免用「・」以外的罕見符號。
8. `project.godot` 設 `renderer/rendering_method="gl_compatibility"`；視窗 1600×900、`canvas_items` 縮放、手機橫式直式都不跑版（直式時兩張地圖改成上下排）。
9. **示範模式** `-- --demo`：自動依序做三件事（每段約 6 秒）：① 原始地圖比賽 ② 自動加一道牆再比賽 ③ 換「隨機迷宮」再比賽，畫面上方顯示目前在示範什麼。
10. **自我測試** `-- --self-test`（不開視窗）：檢查設定檔讀取、地圖尺寸、BFS 步數是最少步數、A* 總花費等於最小花費（另寫一個 Dijkstra 對照）、牆擋住時回報「找不到路」不當掉，最後印 `SELF_TEST PASS …` 或 `SELF_TEST FAIL 原因`。

## 測試時不可以發出聲音
開視窗測試一律加 `--audio-driver Dummy`。本專案不需要任何音效。

## 驗證（一定要做）
```
powershell -ExecutionPolicy Bypass -File <技能包>\scripts\檢查.ps1 -Project .
```
最後印出「全部通過」才算完成。

## 匯出網頁版
```
powershell -ExecutionPolicy Bypass -File <技能包>\scripts\匯出網頁版.ps1 -Project .
```
上線（Netlify）要使用者自己登入，不要索取密碼。

## Godot 在哪裡
練習資料夾旁邊的 `..\Godot\`，或環境變數 `GODOT`。找不到就問使用者，不要自己下載。

## 做完要放的檔案
`開始玩.bat`、`示範模式.bat` 從 scripts 複製到專案；`export_presets.cfg` 從 assets 複製。

## 回報格式（繁體中文、白話）
1. 做好了什麼　2. 自我測試那一行原文　3. 怎麼打開來玩　4. 實測數字（預設地圖兩邊各找了幾格、幾步、花費多少）　5. 下一步可以這樣說（3 句改造例句）
