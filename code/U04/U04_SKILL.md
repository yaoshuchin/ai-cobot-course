# U04 機器人的眼睛技能包

## 你要做的事
使用者是中學老師，不會寫程式。你負責：寫好 Godot 專案 → 自己驗證 → 匯出網頁版 → 用白話回報。做不到的事直接說原因。

## 一定要遵守的規範
1. **Godot 4.7、只用 GDScript**，不用 C#、不裝外掛、不下載素材，3D 物件用內建形狀。
2. 場景用程式建立：`main.tscn` 只放根節點掛 `main.gd`。程式分 `main.gd`、`scene3d.gd`（桌面、物件、機器人）、`vision.gd`（影像處理）、`hud.gd`（面板與滑桿），每個檔都要有中文註解。
3. **虛擬相機**：機器人頭上的 `Camera3D` 放在一個 `SubViewport`（解析度從 `vision.json` 讀，預設 320×240）裡，畫面右上角用 `TextureRect` 顯示「機器人視角」小視窗；按「切換視角」可以讓它放大成全螢幕。
4. **影像處理要自己寫（教學重點）**，在 `vision.gd`：
   - 每 0.2 秒從 SubViewport 取 `Image`，逐像素轉 HSV，依 `vision.json` 每種顏色的 H、S、V 範圍做成遮罩。
   - 連通區域標記（flood fill / BFS），面積小於 `min_area` 的雜點丟掉。
   - 每個物件回傳：顏色名稱、外框（x, y, 寬, 高）、中心點像素座標、面積。
   - 在機器人視角上畫框和中心十字，標籤寫「紅 #1 (152, 98)」。
   - 「遮罩畫面」開關：顯示黑白遮罩，讓學生看到電腦眼中的世界。
5. **場景與操作（亮點）**：
   - 木紋色桌面，散放 9 個物件：紅、綠、藍各 3 個，形狀混合（方塊、球、圓柱），位置隨機；有柔和燈光與陰影。
   - 機器人是一台小車，頭上有相機（看得出鏡頭朝向）；方向鍵／WASD 移動、Q／E 轉頭；手機有虛擬按鈕。
   - 右側面板：偵測清單（顏色、編號、中心座標、面積）、每種顏色的數量統計、H／S／V 門檻滑桿（選顏色後調整，立即生效）、按鈕「重新擺放」「切換視角」「遮罩畫面」。
6. **能讓使用者改的東西全放設定檔**：`vision.json`（相機解析度、各顏色 HSV 範圍、最小面積、更新頻率）、`scene.json`（物件數量、顏色、形狀、桌面大小、隨機種子）、`robot.json`（外觀）。欄位見 `references/設定檔說明.md`。讀不到時用預設值並在左下角提示，不可當掉。
7. 中文字型：`assets/fonts/NotoSansTC-Common.ttf` 複製到 `fonts/`，建 Theme 設成預設字型。
8. `project.godot` 設 `renderer/rendering_method="gl_compatibility"`；視窗 1600×900、`canvas_items`、手機直式時面板移到下方。
9. **示範模式** `-- --demo`：機器人自己慢慢繞桌子轉一圈，每 8 秒自動「重新擺放」一次，並每 5 秒輪流切換「彩色／遮罩」，上方顯示「示範中：機器人正在找紅色物件」等說明。
10. **自我測試** `-- --self-test`（不開視窗，不靠渲染）：在程式裡畫一張 320×240 的測試圖（例如 2 個紅方塊、1 個綠圓、1 個藍方塊加上一些 1～3 像素的雜點），丟給 `vision.gd`，檢查：找到的數量和顏色正確、中心點誤差 ≤ 2 像素、雜點被濾掉；再檢查設定檔讀取。最後印 `SELF_TEST PASS …` 或 `SELF_TEST FAIL 原因`。

## 測試時不可以發出聲音
開視窗測試一律加 `--audio-driver Dummy`。本專案不需要音效。

## 驗證／匯出／Godot 位置
`scripts\檢查.ps1 -Project .`（要「全部通過」）、`scripts\匯出網頁版.ps1 -Project .`；Godot 在練習資料夾旁邊的 `..\Godot\`。`開始玩.bat`、`示範模式.bat`、`export_presets.cfg` 複製到專案。
